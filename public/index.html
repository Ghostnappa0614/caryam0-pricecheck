    Price grabber setup

    The Grab prices bookmark reads the sold prices off an eBay page for you, so you don’t have to type them. You only set it up once.

    Set up in Chrome (one time)

    1. Tap Copy code above.
    2. Open any website in Chrome (Google is fine). Tap the ••• button, then Add to Bookmarks.
    3. Tap ••• again, then Bookmarks. Press and hold the bookmark you just made and tap Edit Bookmark.
    4. Change the name to Grab prices.
    5. Tap the URL box, delete everything in it, and paste. Tap Done.

    Use it (every time)

    1. Tap See sold prices on eBay in step 1.
    2. On the eBay page, tap the address bar at the top and type grab.
    3. Tap Grab prices in the list that pops up. Don’t use the Bookmarks menu for this part; Chrome won’t run it from there.
    4. A yellow card appears. Tap Copy prices, come back here, and paste into step 2.

    Backup: Safari

    1. Tap Copy code above.
    2. In Safari, open any website, tap the Share button, then Add Bookmark. Tap Save.
    3. Tap the Bookmarks button (open book), then Edit. Tap the new bookmark.
    4. Change the name to Grab prices. Clear the address and paste. Tap Done.
    5. To use it: on the eBay page, open Bookmarks and tap Grab prices (or type grab in the address bar and tap it).

    Prices come from eBay’s own sold listings. The “Pay up to” amount is a guide, not a promise.
